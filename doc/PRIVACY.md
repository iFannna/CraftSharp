# 隐私政策

**最后更新日期：2025 年 5 月 25 日**

iFannna（以下简称"开发者"）非常重视用户的隐私保护。本隐私政策说明了 CraftSharp（以下简称"本软件"）如何收集、使用和保护您的信息。请在使用本软件前仔细阅读本政策。

## 1. 信息收集

### 1.1 本软件不收集的内容

本软件的设计原则是尊重用户隐私，我们：

- **不收集**任何个人身份信息
- **不收集**使用行为数据或统计数据
- **不收集**设备信息或系统信息（本地读取的硬件数据仅用于 HUD 数据映射功能，详见第 2 节）
- **不使用**任何分析工具或追踪 SDK
- **不向**任何第三方服务器发送数据

### 1.2 本软件不会联网

本软件仅在以下特定场景会发起网络请求：

- **检查更新**：访问 GitHub API (`api.github.com`) 获取最新版本信息，仅发送标准 HTTP User-Agent 请求头，不附带任何用户信息。
- **下载更新**（如用户主动点击下载）：跳转至 GitHub Releases 页面，由浏览器处理下载。

## 2. 本地数据处理

### 2.1 配置文件

本软件会在本地存储用户偏好设置，包括但不限于：

- 外观设置（主题、字体等）
- 窗口位置和大小
- 壁纸设置
- 快捷键配置
- HUD 元素配置

配置文件保存在应用安装目录下的 `settings.json` 中。

### 2.2 硬件数据读取

本软件的 HUD 数据映射功能会读取以下本地硬件数据，**所有数据仅在本地使用，不会上传或传输**：

| 数据类型 | 读取方式 | 用途 |
|---------|---------|------|
| 电池电量 | Windows 系统 API | 映射到生命值/饥饿值等 HUD 元素 |
| CPU 使用率 | Windows 性能计数器 | 映射到 HUD 元素 |
| 内存使用率 | Windows 性能计数器 | 映射到 HUD 元素 |
| GPU 使用率 | LibreHardwareMonitor 库 | 映射到 HUD 元素 |

### 2.3 开机自启动

如用户启用开机自启动功能，本软件会在 Windows 注册表的以下位置写入一个条目：

`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\CraftSharp`

该条目仅包含本软件可执行文件的路径，卸载时会自动清除。

## 3. 数据安全

3.1 所有用户数据均存储在用户本地计算机上，不会通过网络传输至任何远程服务器。

3.2 本软件不会访问、读取或修改用户的个人文件（壁纸功能仅访问用户指定的图片文件）。

3.3 本软件不会与其他应用程序共享用户数据。

## 4. 第三方组件

本软件使用了以下开源第三方组件：

| 组件 | 用途 | 隐私影响 |
|------|------|---------|
| WPF UI | UI 框架 | 无隐私影响 |
| LibreHardwareMonitor | 硬件监控 | 仅本地读取硬件传感器数据 |
| CommunityToolkit.Mvvm | MVVM 框架 | 无隐私影响 |

## 5. 用户权利

5.1 您有权随时查看、修改或删除本地配置文件（`settings.json`）。

5.2 您有权随时卸载本软件。卸载程序将删除所有应用程序文件、配置文件和注册表项。

5.3 您有权关闭 HUD 数据映射功能，以停止本地硬件数据的读取。

## 6. 政策更新

6.1 开发者可能会不定期更新本隐私政策。更新后的政策将在 GitHub 仓库中发布。

6.2 建议您定期查看本隐私政策以了解任何变更。

如您对本隐私政策有任何疑问或建议，请通过以下方式联系开发者：
